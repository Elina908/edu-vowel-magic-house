# edu-vowel-magic-house

## 仓库定位

这是一个面向儿童英语自然拼读学习的互动 HTML 游戏仓库，主题为“元音魔法学院 / Vowel Magic Academy”。

## 当前内容

- `index.html`：当前主版本，包含元音组合学习、挑战模式和移动端适配界面
- `v1/index.html`：早期版本或备用版本

项目为单文件静态网页实现，主要用于儿童英语元音组合、自然拼读和视觉化互动学习。

## 使用方式

无需安装依赖，直接用浏览器打开：

```text
index.html
```

也可以查看早期版本：

```text
v1/index.html
```
